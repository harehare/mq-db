mq-db

Your Markdown is
already a database.

Interval-indexed block storage for Markdown — query it with SQL or mq, persist it to a compact page-file format. No SQLite dependency.

sql> every block nested under a heading, in one comparison
under()
-- all blocks nested under the "Architecture" heading
SELECT block_type, content FROM blocks
WHERE under(pre, post, arch.pre, arch.post)
ORDER BY pre;
